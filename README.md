# Pacote de documentos para Codex — Guia de Descoberta

Este pacote foi preparado para orientar uma reforma arquitetural progressiva do projeto Django **escola_no_ar_site**, com foco em:
- Vocacional
- Sonhe+Alto / Projeto21
- organização do app `core` como centro da navegação de produtos e do orquestrador de fluxo

## Conteúdo
- `AGENTS.md`
- `docs/arquitetura/00_visao_geral.md`
- `docs/arquitetura/01_objetivo_da_reforma.md`
- `docs/arquitetura/02_arquitetura_alvo.md`
- `docs/arquitetura/03_mapa_de_produtos_e_fluxos.md`
- `docs/arquitetura/04_governanca_dashboard.md`
- `docs/arquitetura/05_plano_fase_1.md`
- `docs/arquitetura/06_checklist_de_aceite.md`
- `docs/arquitetura/07_mensagens_para_codex.md`

## Ordem recomendada de uso
1. Colocar `AGENTS.md` na raiz do repositório.
2. Colocar os documentos em `docs/arquitetura/`.
3. Abrir o projeto no Codex.
4. Pedir que ele leia `AGENTS.md` e os documentos `00` a `05`.
5. Solicitar primeiro diagnóstico e plano.
6. Só depois pedir a implementação da Fase 1.
